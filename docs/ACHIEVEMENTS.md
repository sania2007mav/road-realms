# Достижения

Достижения и статистика живут только в браузере (`localStorage`, ключ `dorozhnye-kraya-meta`). Симуляция их не читает и не пишет, поэтому хеш локстепа не меняется.

Иконки в игре — знаки в списке. Для Steam и Яндекс Игр ниже те же идентификаторы: их можно завести один в один, когда появится площадка. Прогресс в игре считается локально; на площадку уходит только факт открытия.
