# Дорожные края

Открытая браузерная стратегия вдоль одного большого тракта. Поселения стоят по обе стороны дороги.

Люди здесь не абстрактный счётчик. В главном здании сначала живут пятеро. Предел населения — сумма жилья, а каждая работа занимает живого человека. Кончились свободные — нельзя ни назначить работника, ни ускорить стройку.

Сайт: [https://sania2007mav.github.io/road-realms/](https://sania2007mav.github.io/road-realms/)

Политика конфиденциальности: [https://sania2007mav.github.io/road-realms/privacy.html](https://sania2007mav.github.io/road-realms/privacy.html)

## Как запустить

```bash
npm install
npm run dev
```

Сборка для GitHub Pages кладётся в `dist` с базовым путём `/road-realms/`:

```bash
npm test
npm run build
npm run preview
```

Проверка в браузере: `npm run test:e2e`. Архив для Яндекс Игр: `npm run build:yandex` (см. `docs/RELEASE.md`).

## Как играть

1. На заставке выберите условие победы и соседей, затем «Начать». «Продолжить» открывает свежее сохранение. Кампания и сеть — отдельные кнопки.
2. Поставьте **амбар** и **склад** рядом с главным зданием. Пока их нет, еду и материалы некуда донести.
3. Назначьте людей кнопкой «+» в карточке постройки. Жёлтая точка над головой — человек без дела.
4. Яблоневый сад, пшеница и хмель растут только на зелёном оазисе. Лесоруб ставится у леса, каменоломня — на светлом известняке, рудник — на ржавой породе, смолокурня — на чёрном болоте. Охотник работает, только если рядом есть олени.
5. Паёк, число видов еды, налог и пиво в таверне двигают настроение. Выше нуля и при свободном жилье приходят новые люди. Ниже нуля — уходят.
6. Жильё открывается уровнем главного здания: шалаш, бытовка, дом, хрущёвка, многоэтажка.
7. На рынке с торговцем запасы покупаются и продаются сразу. В казарме свободный человек и дерево или железо становятся солдатом.
8. Стены, ворота, башни и ров со смолой держат осаду. «Выделить войска» задаёт стоять, идти домой или атаковать область.

Победа в свободной партии зависит от выбранного условия: завоевание, богатство, расцвет или выживание. Поражение — потерять своё главное здание.

Сохранение пишется в `localStorage` этого браузера: три ячейки и автосохранение. Мир собирается из зерна и идёт тактами.

## Управление

- Мышь: тянуть карту, колесо — масштаб, край экрана листает карту.
- Телефон: два пальца двигают и меняют масштаб, долгое нажатие открывает постройку. Кнопка «Карта» показывает миникарту. Скорость и звук — в меню.
- Клавиши: WASD или стрелки, Z X C V B N — вкладки построек, пробел — пауза, 1–3 — скорость, Esc закрывает панели, H — подсказки.

## Режимы

- **Одиночная игра.** Свои соседи-боты или пустой тракт. Четыре условия победы, размер карты и запасы.
- **Кампания.** Остановки вдоль тракта со звёздами. Прогресс хранится в браузере, сеть не нужна.
- **Сетевая игра.** Комната на двоих, троих или четверых. Вход в Firebase анонимный. Если сеть недоступна, на экране лобби будет сказано, что одиночная игра и кампания работают без подключения.

Справка на заставке и в меню объясняет постройки. «Об игре» называет автора и то, что рисунок и звук собраны кодом.
