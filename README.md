# Дорожные края

Открытая браузерная стратегия вдоль одного большого тракта. Рабочее имя было «Дорога»; в игре поселения стоят по обе стороны дороги, поэтому она называется **Дорожные края**.

Люди здесь не абстрактный счётчик. В главном здании сначала живут пятеро. Предел населения — это сумма жилья, а каждая работа занимает живого человека. Кончились свободные — нельзя ни назначить работника, ни ускорить стройку.

Сайт: [https://sania2007mav.github.io/road-realms/](https://sania2007mav.github.io/road-realms/)

## Как запустить

```bash
npm install
npm run dev
```

Сборка для GitHub Pages кладётся в `dist` с базовым путём `/road-realms/`:

```bash
npm test
npm run build
npm run preview
```

Проверка в браузере: `npm run test:e2e`.

## Как играть

Колесо и щипок приближают карту, перетаскивание её двигает. С телефона то же самое пальцем. Клавиши: WASD или стрелки, пробел — пауза, 1–3 — скорость, Esc — отмена стройки, H — подсказки.

1. Поставьте **амбар** и **склад** рядом с главным зданием. Пока их нет, еду и материалы некуда донести.
2. Назначьте людей кнопкой «+» в карточке постройки. Жёлтая точка над головой — человек без дела.
3. Яблоневый сад, пшеница и хмель растут только на зелёном оазисе. Лесоруб ставится у леса, каменоломня — на светлом известняке, рудник — на ржавой породе, смолокурня — на чёрном болоте. Охотник работает, только если рядом есть олени.
4. Паёк, число видов еды, налог и пиво в таверне двигают настроение. Выше нуля и при свободном жилье приходят новые люди. Ниже нуля — уходят.
5. Жильё открывается уровнем главного здания: шалаш, бытовка, дом, хрущёвка, многоэтажка.
6. На рынке с торговцем запасы покупаются и продаются сразу. В казарме свободный человек и дерево или железо становятся солдатом.
7. Победа — разрушить главные здания соседей. Поражение — потерять своё.

Сохранение пишется в `localStorage` этого браузера. Мир собирается из зерна и идёт тактами: одни и те же команды дают один и тот же результат.

## Что есть в первой версии

- Большая карта в изометрии (ромбы 2:1), зум и прокрутка, процедурный мир от зерна.
- Прямой тракт. Игроки встают по очереди сверху и снизу, далеко друг от друга. Между ними нейтральные звери, разбойники и залежи.
- Настоящие люди, предел от жилья, работы, строители, которые идут пешком, носильщики и волы для камня и железа.
- Четыре еды: яблоки, сыр, мясо, хлеб (ферма → мельница → пекарня). Хмель → пивоварня → таверна.
- Паёк, разнообразие, налог, пиво, чума на молочной ферме.
- Дерево, камень, железо, смола, рынок.
- Верхняя панель: занятые, свободные и предел, настроение с причинами, золото, еда и ресурсы.
- Два или три соседа с теми же правилами экономики. Иногда они посылают солдат в набег.
- Миникарта, скорости пауза/1×/2×/3×, сохранение, короткие подсказки.
- Солдаты: ополченец из дерева и мечник из железа.

Симуляция тактовая и отделена от отрисовки: команда — это событие, картинка его не считает. Так позже можно добавить сеть, не переписывая экономику.

## Что упрощено или отложено

- Нет стен, башен, ворот и рвов с горящей смолой.
- Нет чумных коров и осадных машин.
- Нет сетевой игры: архитектура команд уже отделена от кадра, но протокола ещё нет.
- Постройки не перекрывают шаг, чтобы люди не застревали. Расстояние всё равно решает, потому что носить груз приходится ногами.
- Лес не вырубается до конца.
- Соседи играют по короткому списку целей, а не как живой противник на всю партию.
- Войско — только ближний бой. Солдат защищает посад или идёт к чужому главному зданию.

## Управление разработкой

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Локальная игра |
| `npm test` | Правила населения, еды, налогов, цепочек, расстановки и детерминизма |
| `npm run build` | Статическая сборка в `dist` |
| `npm run test:e2e` | Партия в Chromium: стройка, назначение, несколько игровых минут |
